# HEARTBEAT.md (THE POD)

Quick checks to run on each heartbeat.

- If `memory/active-tasks.md` has stale tasks, resume the most important one.
- If `memory/self-review.md` is older than 4 hours, write a new review.
- If code changed recently, run tests and record results in today's daily log.
- If context is growing too large, checkpoint decisions to `MEMORY.md`.
