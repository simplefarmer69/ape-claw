Powered by OpenClaw
ApeClaw is an OpenClaw skill. Your OpenClaw agent discovers and uses ape-claw automatically through the skill system. Install OpenClaw first, then add the ape-claw skill.
Get OpenClaw
0

Install OpenClaw

OpenClaw is your personal AI agent. Install it first:

curl -fsSL https://openclaw.ai/install.sh | bash

Or via npm:

npm i -g openclaw
openclaw onboard

See openclaw.ai for full setup guide.

1

Install the ape-claw skill

Run the one-command installer (works without cloning repo):

curl -fsSL https://raw.githubusercontent.com/simplefarmer69/ape-claw/main/install.sh | bash

Installs ApeClaw skill + OpenClaw CLI (if missing) and bootstraps config.

2

Register your Clawllector

Each Clawllector gets a unique agent ID. Save the token — it's shown only once:

npx --yes github:simplefarmer69/ape-claw clawbot register \
  --agent-id my-bot \
  --name "My Bot" --json

Returns {"token":"claw_..."} — store this securely.

3

Configure env vars

Set your agent credentials and private key:

export APE_CLAW_AGENT_ID=my-bot
export APE_CLAW_AGENT_TOKEN=claw_...
export APE_CLAW_PRIVATE_KEY=0x...

Verified Clawllectors auto-receive the shared OpenSea API key — no need for your own.

4

Run preflight check

Verify everything is configured correctly:

npx --yes github:simplefarmer69/ape-claw doctor --json

Should return "ok": true. If "executeReady": false, read-only flows still work; add private key for execute.

5

Start collecting

Your OpenClaw agent can now browse, quote, simulate, and buy ApeChain NFTs:

npx --yes github:simplefarmer69/ape-claw market collections \
  --recommended --json
npx --yes github:simplefarmer69/ape-claw nft quote-buy \
  --collection dongsocks \
  --tokenId 42 --maxPrice 100 \
  --currency APE --json

Start the dashboard with node ./src/telemetry-server.mjs to see live activity.
